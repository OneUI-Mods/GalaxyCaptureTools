# Galaxy Capture Tools

Android / Galaxyの既存の画面録画を拡張する実験的なVectorモジュールです。

- 動画の開始時の縦横サイズを固定し、端末回転時に映像を90度回して黒帯をなくす。
- Galaxyの「録画するエリア」に、アプリとウィンドウの選択を統合する。
- アプリ録画を選択時のメインウィンドウへ固定する追加設定。
- 録音する音声を対象アプリのみ／端末全体から選ぶ。
- 180度の持ち替えを無視する設定。縦・横どちらの開始向きにも対応。
- Material 3、日本語・英語・韓国語・簡体字・繁体字、個別ON/OFFとクラッシュ保護。

開発中です。対応確認・配布前の実機試験はまだ完了していません。

対象はSM-S948Q / Android 16 / One UI 8.5、ビルドBP4A.251205.006.S948QOPS1AZHL、Samsung Capture 6.1.76.9。Vectorの対象はシステムフレームワーク、SystemUI、Samsungキャプチャ。初回の読み込み直しはソフトリブートを使います。設定は次の録画開始から反映します。

AOSPの[アプリ単位の共有・録画](https://developer.android.com/about/versions/14/features/app-screen-sharing)を基準にしています。対象選択のキャンセルは録画の中止として扱います。

回転以外の理由でウィンドウの縦横比が変わった場合は、内容を切り落とさないため余白が残る場合があります。保護画面の録画制限は維持します。Galaxyでは表示中のウィンドウを選択します。Android標準のアプリ録画では、固定設定をONにすると選択時のメインウィンドウが対象になります。
