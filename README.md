# Galaxy Capture Tools

Android標準とSamsungの画面録画・スクリーンショットを拡張する、実験的なVectorモジュールです。

## 主な機能

- 録画開始時の動画サイズを保ち、端末回転時の映像を90度回して黒帯を抑える。
- 180度の持ち替えを無視する設定。黒帯補正とは独立して切り替え可能。
- Samsungの「録画するエリア」からアプリ・ウィンドウを選択。専用画面で履歴・一覧・検索を使用。
- 選択したメインウィンドウだけに録画を固定する追加設定。
- アプリ録画時に、録音する音を対象アプリのみ／端末全体から選択。
- メディアとマイクの録音、スピーカー時のマイク優先分岐、Samsung録画用の音量調整。
- 録画操作バー・カウントダウン・重複した右側のミラーリングアイコンを個別に調整。
- Samsungの録画操作表示を右側へ移動。元のタップ操作による停止も維持。縦画面向け、初期OFF。
- 録画の回転時や連続スクリーンショットで、操作UIが映り込む問題への対策。
- スクリーンショット・録画の制限解除を別々に設定。初期OFF。
- Samsungキャプチャ設定内の「カスタム設定」と専用アプリが連動。

## 対応環境

Galaxy S26 Ultra（SM-S948Q）のAndroid 16 / One UI 8.5（AZHL）とAndroid 17 / One UI 9（BZI9）を別の互換処理で扱います。対応するroot環境とlibxposed API 102対応Vectorが必要です。Samsungキャプチャやシステムの対応版は[互換性情報](docs/compatibility/android17.md)を参照してください。

## 導入・使い方

1. [Releases](https://github.com/OneUI-Mods/GalaxyCaptureTools/releases)の署名済みrelease APKをインストールします。同じパッケージの更新は上書きできます。
2. Vectorでモジュールを有効にし、Androidシステム、SystemUI、Samsungキャプチャを対象に選択します。初回のシステム側の読み込みにはシステムの起動し直しが必要です。
3. アプリで全体スイッチをONにし、必要な機能を個別に選びます。全体スイッチがOFFなら、個別の設定値を保存したまますべての拡張を停止します。
4. 設定は次の録画・撮影から反映します。重要な録画の前には短い録画で映像・音声を確認してください。

アプリは「共通」「Galaxy」「状態」「情報」に分かれています。「共通」はAndroid標準とGalaxyの両方、「Galaxy」はSamsungキャプチャ専用です。設定アプリからは「便利な機能 → 画面キャプチャと画面録画 → カスタム設定」を開けます。

## 制限・停止

Samsungの「画面の一部」には回転補正を適用しません。回転以外の縦横比変更では、内容を切り落とさないため余白が残る場合があります。固定したウィンドウを離れると、他のアプリを映す代わりに黒画面や直前の映像になります。付属するメニュー・ポップアップが一緒に映る場合もあります。

対象アプリだけの音声はアプリ側の再生キャプチャ制限にも従います。DRMなどで保護された一部の描画は、制限解除をONにしても黒くなる場合があります。音量調整は録画用で、本体の再生音量は変更しません。

停止は全体スイッチをOFFにします。完全に外す場合はVectorで無効にして対象プロセスを再読み込みします。異常終了で保護が働いた場合は、原因を解消してから解除してください。
