# Galaxy Capture Tools

libxposed API 102対応のVector（検証環境：2.2）が必要です。旧API 82への互換読み込みは行いません。更新後はVectorの対象設定を確認し、ソフトリブートしてください。

Android / Galaxyの既存の画面録画を拡張する実験的なVectorモジュールです。

- 動画の開始時の縦横サイズを固定し、端末回転時に映像を90度回して黒帯をなくす。
- Galaxyの「録画するエリア」に、アプリとウィンドウの選択を統合する。専用の選択画面で履歴・全アプリ・検索から選べる。
- アプリ録画を選択時のメインウィンドウへ固定する追加設定。
- Android標準・Galaxyの開始画面で、録音する音声を対象アプリのみ／端末全体から選ぶ。
- 左側の録画通知を残し、右側の重複したミラーリングアイコンを隠す設定。
- Galaxyの録画操作バーを隠す設定と、録画・連続スクリーンショットへの操作UIの映り込みを防ぐ設定。
- Galaxy録画前のカウントダウンを切り替える設定。
- スクショ・画面録画の制限を別々に解除する設定（初期OFF）。
- Samsung録画用のメディア音量・マイク音量を、本体音量と独立して調整。
- Samsungキャプチャの設定画面に独立したカスタム設定を追加し、アプリ側と同期。
- 180度の持ち替えを無視する設定。縦・横どちらの開始向きにも対応。
- アプリUIはMaterial 3、Samsung設定内の追加画面はOne UI標準の部品・レイアウトを使用。
- 日本語・英語・韓国語・簡体字・繁体字、個別ON/OFFとクラッシュ保護。

実験版です。上記の主な機能を下記の実機環境で確認しています。重要な録画の前には短い録画で動作を確認してください。

対象はSM-S948Q / Android 16 / One UI 8.5、ビルドBP4A.251205.006.S948QOPS1AZHL、Samsung Capture 6.1.76.9。Vectorの対象はシステムフレームワーク、SystemUI、Samsungキャプチャ。初回の読み込み直しはソフトリブートを使います。設定は次の録画開始から反映します。

AOSPの[アプリ単位の共有・録画](https://developer.android.com/about/versions/14/features/app-screen-sharing)を基準にしています。対象選択の「戻る」は録画開始画面へ戻ります。録画開始画面のキャンセルで録画を中止します。

回転以外の理由でウィンドウの縦横比が変わった場合は、内容を切り落とさないため余白が残る場合があります。保護画面の制限は、スクショ・録画それぞれの制限解除設定をONにした場合に限り変更します。DRMなどで保護された動画や一部の描画は黒くなる場合があります。Galaxyでは表示中のウィンドウを選択します。Android標準のアプリ録画では、固定設定をONにすると選択時のメインウィンドウが対象になります。

全体スイッチがOFFの間はすべての拡張を停止し、個別設定を無効表示にします。個別設定の値は保存します。180度の持ち替えを無視する設定は黒帯補正と独立しています。

回転補正は全画面・アプリ・ウィンドウが対象で、Samsungの「画面の一部」には適用しません。ウィンドウを離れたときは、他の画面を映す代わりに黒画面や直前の映像になります。付属するメニューやポップアップは一緒に映る場合があります。対象アプリだけの音声は、アプリ側の再生キャプチャ制限にも従います。

導入手順と制限は[リリース案内](docs/releases/0.3.0-experimental.md)、署名付きAPKの作成手順は[配布手順](docs/releasing.md)を参照してください。

設定画面は「共通」「Galaxy」「状態」「情報」のタブから操作できます。「共通」はAndroid標準（AOSP）とGalaxyの両方に適用し、「Galaxy」はSamsungキャプチャ専用です。全体スイッチはどのタブでも表示します。ライセンスは検索可能な一覧から、各ライブラリの本文・著作権表示を確認できます。
