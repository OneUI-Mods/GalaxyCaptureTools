Samsungキャプチャの初回表示でも、アプリ・ウィンドウ録画の選択肢が表示されるよう改善しました。設定の読み込みが遅れた場合も、録画画面を開き直す必要がありません。

「内部音声に通話音声を含める」はSamsung・Android標準の録画に共通で、初期値はOFFです。「対象アプリの音声のみ」では、ONにしても選んだアプリの範囲を維持します。マイクは録音モードの選択に従い、変更は次の録画から反映されます。

対応するGalaxy S26 Ultra（SM-S948Q）のAndroid 16 / One UI 8.5、Android 17 / One UI 9と、root・libxposed API 102対応Vectorが必要です。署名済みrelease APKを上書きしてください。0.3.6からの更新ではSamsungキャプチャを一度強制終了して開き直すと反映されます。それ以前の版から通話音声機能を導入する場合はソフトリブートしてください。

通話音声は実験的な機能です。携帯回線・Bluetooth・アプリ独自の音声経路では収録できない場合があります。メディア扱いの音声やマイクに入る音声は、このスイッチのOFFだけでは除外できません。Android標準録画では、保存が完了してから次の録画を開始してください。
