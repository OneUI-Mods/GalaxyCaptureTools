# 録画開始時のアイコン移動を改善

録画アイコンを右側へ移す設定がONのとき、開始直後に一瞬左側へ表示される問題を修正しました。右側の録画アイコンから開く停止操作は引き続き利用できます。

Android 16の既存対応を維持しています。Android 17はGalaxy S26 Ultra（SM-S948Q、BZI9）向けの実験対応です。rootとAPI 102対応のVectorが必要です。

署名済みrelease APKを上書きインストールし、録画を終了してからSystemUIを読み込み直してください。Galaxy Reloadを利用できます。右側の空きが足りない場合や横画面・外部キャストでは、従来どおり純正の表示位置を使います。
