# キャプチャの個別設定とSamsung設定画面への統合

スクリーンショットと画面録画の制限を、別々のスイッチで解除できるようになりました。どちらも初期設定はOFFです。

Samsungキャプチャの設定画面に「カスタム設定」への入口を追加しました。別画面で映像・音声・録画の開始と操作・スクショに分けて変更でき、上部の大きな全体スイッチからON/OFFを切り替えられます。戻る操作で元の設定画面へ戻れます。アプリ側と同じ設定を使うため、変更内容は両方へ反映されます。

Samsungの録画用に、メディアとマイクの音量を個別に調整できます。本体の音量は変わりません。対象アプリの音声だけを録る場合にも適用され、録画音量の調整をOFFにすると純正の音量処理へ戻ります。

対応環境はGalaxy SM-S948Q、Android 16 / One UI 8.5、ビルドBP4A.251205.006.S948QOPS1AZHL、Samsung Capture 6.1.76.9です。libxposed API 102対応のVectorが必要です。

更新後はシステムフレームワーク・SystemUI・Samsungキャプチャへの適用を確認し、ソフトリブートして端末を解除してください。録画向けの設定変更は次の録画から反映されます。

実験版です。制限解除は通常の保護画面が対象で、DRMなどで保護された動画・一部の描画は黒くなる場合があります。スクロールキャプチャなど追加の取得経路では制限が残る場合があります。アプリ音声の録音可否は再生アプリ側の方針にも従います。
