# Galaxy Capture Tools 0.2.1 実験版

「音声・表示」に、Galaxyの録画操作バーを端末上で非表示にする設定を追加しました。非表示中は通知、またはクイック設定の「画面録画」タイルから停止できます。初期状態では操作バーを表示します。

「操作UIの映り込みを防ぐ」を追加しました。録画操作バーを表示したままでも、回転時を含めて保存映像へ入らないようにします。スクリーンショット後の操作バーとサムネイルも保存画像から除外し、続けてスクリーンショットを撮れます。端末上でのスクロールキャプチャなどの操作は維持します。初期状態はONです。

「録画」に、Galaxy録画前のカウントダウン設定を追加しました。OFFでは録画するエリアと音声の確定後、3秒の待ち時間を省略します。初期状態はONです。

各設定は全体スイッチに従い、次の録画・スクリーンショットから反映します。

## 対応環境と更新

SM-S948Q / Android 16 / One UI 8.5（BP4A.251205.006.S948QOPS1AZHL）、Samsung Capture 6.1.76.9、API 102対応Vector（検証環境：2.2）が対象の実験版です。機能にはrootとVectorが必要です。

既存版を削除せず、署名済みrelease APKで上書きしてください。録画を停止した状態でSamsungキャプチャを読み込み直すか、ソフトリブートしてください。Vectorの対象はシステムフレームワーク・SystemUI・Samsungキャプチャです。設定は引き継ぎます。

## 制限

今回の録画操作バーとカウントダウンの設定はGalaxyの録画が対象です。カメラ映像・描画した線・他アプリの操作UIを一括で消す設定ではありません。操作バーの設定は全画面・アプリ・ウィンドウ録画のフローティングバーが対象で、「画面の一部」の選択・操作UIは対象外です。DeX・外部画面では動作未確認です。保護された画面やアプリが禁止する音声の制限は維持します。
