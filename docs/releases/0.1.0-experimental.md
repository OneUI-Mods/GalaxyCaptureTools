Galaxyの画面録画を拡張するVectorモジュールの初回実験版です。

- Galaxyの「録画するエリア」に、元のデザインに合わせたアプリ・ウィンドウの選択を追加しました。
- 動画の幅と高さを開始時に固定したまま映像を90度回し、端末回転による黒帯を減らします。
- 180度の持ち替えを無視する設定を追加しました。縦・横どちらで開始しても使え、黒帯補正とは別に設定できます。
- アプリ録画の音声を「対象アプリのみ／端末全体」から選べます。マイクの設定は従来の録画画面で選択します。
- ウィンドウ録画では、同じアプリの別画面へ録画対象を切り替えません。
- 全体スイッチ、個別設定、異常時の停止保護、日本語・英語・韓国語・簡体字・繁体字に対応しました。

### 対応環境

rootとVectorが必要です。動作確認済みの環境はGalaxy SM-S948Q、Android 16 / One UI 8.5、ビルドBP4A.251205.006.S948QOPS1AZHL、Samsung Capture 6.1.76.9です。ほかのビルドでは機能を有効にしません。この環境のAndroid標準の録画経路にも対応しています。

### 導入

添付のrelease APKをインストールし、Vectorで「システムフレームワーク」「SystemUI」「Samsungキャプチャ」を対象に設定してソフトリブートしてください。解除後、アプリの「すべての録画拡張」をONにします。個別設定の変更は次の録画から反映されます。全体スイッチがOFFの間はすべての拡張を停止し、個別設定の値は保存します。

### 既知の制限

- 実験版のため、重要な録画の前には短い録画で動作を確認してください。
- 保護された画面や、アプリ側で禁止されている音声は録画できません。
- 回転補正は全画面・アプリ・ウィンドウが対象です。Samsungの「画面の一部」には適用しません。回転以外の理由で縦横比が変わった場合、内容を切り落とさないため余白が残る場合があります。
- 選択したウィンドウを離れると、他の画面を映す代わりに黒画面または直前の映像になります。ウィンドウに付属するメニューやポップアップは一緒に映る場合があります。
- 異常で保護停止した場合は、設定画面から保護を解除してソフトリブートしてください。

配布APKはrelease variantでビルドし、署名を検証しています。検証用アプリは含みません。
