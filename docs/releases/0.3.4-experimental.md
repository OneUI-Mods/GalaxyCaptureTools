# Android 17向けSDKへ更新

Android 17のSDKへ更新しました。Android 16用の対応と保存済みの録画設定を維持しています。

Android 17はGalaxy S26 Ultra（SM-S948Q、BZI9）の実験対応です。Samsungキャプチャの対応する版と、root・API 102対応Vectorが必要です。未対応の端末・ファームウェアでは機能を停止します。Galaxyに存在しないAOSP標準録画画面の実機確認は含みません。

署名済みrelease APKを上書きインストールしてください。この更新のSDK変更は設定アプリ向けです。録画中の場合は録画を終了してから更新し、設定画面を開き直してください。既存のAndroid 17対応版からは、端末の再起動や設定の削除は不要です。
