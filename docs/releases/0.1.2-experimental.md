# Galaxy Capture Tools 0.1.2 実験版

設定画面を「録画」「音声・表示」「状態」「情報」の4つのタブに整理しました。設定と各タブのスクロール位置を保持します。ライセンスは検索できる一覧から、ライブラリごとに本文と著作権表示を開けます。

0.1.0からは、次の録画機能も追加されています。

- 「録画するエリア」のアプリ・ウィンドウを押すと、Galaxyキャプチャと同じスタイルの選択画面が開きます。「戻る」や端末の戻る操作で、録画開始画面へ戻れます。
- アプリ選択では、最初にアプリ履歴を最近使った順に表示します。スクロールして選べるほか、「その他のアプリ」や検索から履歴にないアプリも探せます。
- 選択すると元の開始画面へ戻り、録画対象と音声の範囲を確認してから録画を開始できます。対象の選び直しを取り消した場合は、前の選択を保持します。

- Android標準の録画開始画面では、1つのアプリを録画するときに、端末内の音声を「対象アプリのみ／端末全体」から選べます。音声なし・マイクのみの場合は無効表示になり、画面全体の録画では表示しません。

- 録画中に右側へ重複して出るミラーリングアイコンを隠す設定を追加しました。左側の録画通知は残り、外部画面へのキャスト表示も維持します。設定をOFFにすると標準の表示へ戻せます。

## 対応環境と更新

root化されたGalaxy、Vectorが必要です。対応を確認している環境はSM-S948Q / Android 16 / One UI 8.5、Samsung Capture 6.1.76.9です。他の機種・OS・キャプチャのバージョンでは動作しない場合があります。

既存版へ署名済みrelease APKを上書きインストールし、ソフトリブートしてください。Vectorの対象はシステムフレームワーク、SystemUI、Samsungキャプチャです。アプリの全体スイッチと、使用する個別機能をONにしてください。設定は次の録画から反映します。

## 制限

実験版です。Android標準の録画開始画面の音声範囲選択と、重複アイコンの抑制は検証途上です。Galaxyのウィンドウ選択は表示中のウィンドウが対象です。対象の選択は一定時間で期限切れになるため、時間を置いた場合は選び直してください。ウィンドウに付属するメニューやポップアップは一緒に映る場合があります。

保護された画面や、アプリが許可していない音声は録画・録音できません。回転補正はGalaxyの「画面の一部」には適用しません。回転以外で縦横比が変化した場合には余白が残る場合があります。
