# Galaxy Capture Tools 0.2.0 実験版

libxposed API 102へ移行しました。API 102対応のVectorが必要です。旧API 82専用の環境では読み込めません。

Galaxyの「アプリ」録画で「対象アプリのみ」と「メディアとマイク」を選んだとき、スピーカー出力中にアプリの内部音声が入らない問題を修正しました。

「音声・表示」に「スピーカーでも内部音声を含める」を追加しました。初期値はONです。Galaxy標準の混音処理を使い、スピーカー時にマイクのみとなる分岐を切り替えます。OFFでは元の動作に戻り、スピーカー出力中の録画開始画面は「マイクのみ」と表示します。イヤホンへ切り替えると元の表示へ戻ります。設定変更は次の録画から反映します。

起動時とアプリ更新後に、保存された設定を自動で読み込み直します。通常起動・ソフトリブート後とも、最初のロック解除後に復帰します。自動復帰自体はrootコマンドや常駐サービスを使いません。全体OFFの状態とクラッシュ保護は維持します。

## 対応環境と更新

SM-S948Q / Android 16 / One UI 8.5、Samsung Capture 6.1.76.9を対象とする実験版です。録画拡張には従来どおりrootとAPI 102対応のVector（検証環境：2.2）が必要です。

既存版を削除せず、署名済みrelease APKを上書きし、ソフトリブートしてください。Vectorの対象はシステムフレームワーク、SystemUI、Samsungキャプチャです。保存された設定を引き継ぎます。

## 制限

アプリが禁止している内部音声や、保護された画面は録音・録画できません。内部音声の録音音量はGalaxy標準の音量設定に従います。マイクを有効にすると、周囲の音やスピーカーから聞こえる音も入ります。スピーカー時の分岐を切り替える設定はGalaxyの「メディアとマイク」に適用し、Android標準の録画は標準の混音処理を使います。

Galaxyのウィンドウ録画では、付属するメニューやポップアップも一緒に映る場合があります。回転補正は「画面の一部」には適用しません。
