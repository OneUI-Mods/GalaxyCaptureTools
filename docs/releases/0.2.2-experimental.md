# Galaxy Capture Tools 0.2.2 実験版

設定画面を「共通」「Galaxy」「状態」「情報」に整理しました。

「共通」には、Android標準（AOSP）とGalaxyの両方で使う回転補正・ウィンドウ録画・音声の既定範囲・重複アイコンの設定をまとめています。ページ上部に対象を明記し、ウィンドウ録画の説明もそれぞれの録画での動作が分かる内容へ変更しました。

「Galaxy」には、Samsungキャプチャ専用の録画対象選択・カウントダウン・スピーカー音声・操作UIの設定をまとめました。開始、音声、操作UIの見出しで探せます。

全体スイッチはタブの上へ移し、どのページでも確認・切り替えられます。OFF中は両方の録画の拡張を停止し、個別設定の値は保持します。既存の設定値と録画機能の動作は引き継ぎます。

## 対応環境と更新

SM-S948Q / Android 16 / One UI 8.5（BP4A.251205.006.S948QOPS1AZHL）、Samsung Capture 6.1.76.9、API 102対応Vector（検証環境：2.2）が対象の実験版です。録画拡張にはrootとVectorが必要です。

既存版を削除せず、署名済みrelease APKで上書きし、設定アプリを開き直してください。今回の変更は設定画面の整理です。

## 制限

対応する録画機能は従来と同じです。操作バーの設定は全画面・アプリ・ウィンドウ録画のフローティングバーが対象で、「画面の一部」の選択・操作UIは対象外です。DeX・外部画面では動作未確認です。保護された画面やアプリが禁止する音声の制限は維持します。
