内部音声に通話の再生音を含めるか、個別に選べるようになりました。

- 「共通 → 音声・表示」に「内部音声に通話音声を含める」を追加しました。初期値はOFFです。
- Samsungキャプチャ設定の「カスタム設定 → 音声」にも同じ項目があり、専用アプリと連動します。
- 「対象アプリの音声のみ」を選んでいる場合、通話音声をONにしても対象はそのアプリのままです。たとえばDiscordで通話すると、そのアプリの通常音声と通話の再生音が対象になります。別アプリの通話音を追加しません。
- マイクは「録音する音声」の選択に従います。設定変更は次の録画から反映します。

Galaxy S26 Ultra（SM-S948Q）の対応するAndroid 16 / One UI 8.5とAndroid 17 / One UI 9、rootとlibxposed API 102対応Vectorが必要です。署名済みrelease APKを上書きし、通話音声の機能を読み込むためソフトリブートしてください。

通話音声は実験的な機能です。携帯回線の通話やBluetoothなどの音声経路、アプリ独自の処理では収録できない場合があります。メディア扱いの音声やマイクに入る音声は、通話音声OFFだけでは除外できません。端末やアプリの組み合わせによって両側の会話を収録できる保証はありません。
