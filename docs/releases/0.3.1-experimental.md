# Galaxy Capture Tools 0.3.1

Galaxyタブに「録画中アイコンを右側に表示」を追加しました。左側にある赤い録画表示を、タップ操作も含めて右側へ移します。右側の表示をタップすると、従来と同じSamsungの録画停止ダイアログを開けます。重複するミラーリングアイコンは隠します。

初期設定はOFFです。録画中でもON/OFFでき、OFFにすると左側へ戻ります。

Samsungの設定アプリからは「便利な機能 → 画面キャプチャと画面録画 → カスタム設定 → 録画の開始・操作」で変更できます。モジュールアプリと設定を共有します。

## 対応環境と更新

SM-S948Q / Android 16 / One UI 8.5（BP4A.251205.006.S948QOPS1AZHL）、Samsung Capture 6.1.76.9、API 102対応Vector（検証環境：2.2）向けの実験版です。rootとVectorが必要です。APKを上書きインストールし、SystemUIを読み込み直してください。フック対象の追加はありません。

## 制限

移動対象はGalaxy純正の画面録画表示です。縦画面のメインディスプレイに対応します。横画面・別の画面共有・非対応の配置・右側に表示領域を確保できない場合は、左側の標準表示へ戻します。DeX・外部画面・別バージョンのOne UIでの動作は未確認です。
