# Galaxy Capture Tools 0.1.3 実験版

Galaxyの「アプリ」録画で「対象アプリのみ」と「メディアとマイク」を選んだとき、スピーカー出力中にアプリの内部音声が入らない問題を修正しました。

「音声・表示」に「対象アプリの音声とマイクを直接ミックス」を追加しました。初期値はONです。OFFではGalaxy標準の混音処理を使い、スピーカー出力中の録画開始画面は「マイクのみ」と表示します。イヤホンへ切り替えると元の表示へ戻ります。設定変更は次の録画から反映します。

起動時とアプリ更新後に、保存された設定を自動で読み込み直します。通常起動・ソフトリブート後とも、最初のロック解除後に復帰します。自動復帰自体はrootコマンドや常駐サービスを使いません。全体OFFの状態とクラッシュ保護は維持します。

## 対応環境と更新

SM-S948Q / Android 16 / One UI 8.5、Samsung Capture 6.1.76.9を対象とする実験版です。録画拡張には従来どおりrootとVectorが必要です。

既存版を削除せず、署名済みrelease APKを上書きし、ソフトリブートしてください。Vectorの対象はシステムフレームワーク、SystemUI、Samsungキャプチャです。保存された設定を引き継ぎます。

## 制限

アプリが禁止している内部音声や、保護された画面は録音・録画できません。マイクを有効にすると、周囲の音やスピーカーから聞こえる音も入ります。直接ミックスの設定はGalaxyの対象アプリ録画に適用し、Android標準の録画は標準の混音処理を使います。

Galaxyのウィンドウ録画では、付属するメニューやポップアップも一緒に映る場合があります。回転補正は「画面の一部」には適用しません。
