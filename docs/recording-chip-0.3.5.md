# 録画アイコンと音声ラベルの確認（2026-10-23）

署名済みrelease版、SM-S948Q / Android 17 BZI9で確認。SystemUIはGalaxy Reload経由で一度のみ読み込み直し、ロックなしで復帰した。本体・ホーム・system_serverは再起動していない。

Samsungの全画面・無音録画開始をshell側の別録画で収録した。58フレームを抽出し、開始フェード中から録画チップが右側へ現れることを目視確認した。赤画素の検出も右側（720幅でx456–507）に限定された。左側から右側へ移るフレームはなかった。別録画の取得開始とタップを別々のコマンドにした初回収録は開始前に終わっていたため、確認資料から除外した。右側のネイティブ表示をタップして純正の停止ダイアログを開き、停止後にMediaProjectionがnullになることも2回確認。

音声ラベルはSamsung実機APKのEnhancedRadioButtonとRecorderDialogAlertTheme・secフォントをロードして、文字倍率0.85/1.0/1.3/1.5/2.0、横幅280/360/600/900dpの20組で計測。2行になる場合の1行目「メディアと」、2行目「マイク」、省略表示なし、900dpでは全倍率で1行、マイクのみおよび全体OFF時の文言・幅復元を確認した。テストの最初の失敗はホストtheme未指定によるinflateエラー、次の失敗は600dp・2倍でも必ず1行になるという誤ったテスト条件で、どちらもテスト側を修正した。端末本体のfont_scaleは変更していない。実際のSamsung開始ダイアログでも意図した2行表示を目視確認。

録画は停止済み、音声選択は検証前の「メディア」へ復元、開始画面はキャンセル。検証APKは削除する。Android 16、横画面、右側の空き不足・外部castは今回再試験していない。既存の別経路と復元条件を維持している。
